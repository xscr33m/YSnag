## Creating a Derivative Work (Fork)

If you create a derivative work based on YSnag, you must:

1. **Choose a different name** — Your project cannot include "YSnag" in its name
2. **Create new branding** — Design your own logo and visual identity
3. **Remove YSnag branding** — Strip all YSnag logos, icons, and branded elements from the code
4. **Provide attribution** — Include a notice such as:
   ```
   This software is based on YSnag (https://github.com/xscr33m/YSnag)
   Originally created by xscr33mLabs
   ```
5. **Comply with GPL v3** — Your derivative work must also be licensed under GPL v3
